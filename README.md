# Law-Aid Web Platform ⚖️

Official repository for the **Law-Aid** planning and management portal, live at [plan.law-aid.org](https://plan.law-aid.org/).

This platform provides a streamlined digital workspace designed to facilitate legal aid management, strategic planning, resource coordination, and access to legal justice tools.

---

## 🚀 Live Demo

* **Production URL:** [https://plan.law-aid.org](https://plan.law-aid.org/)
* **Vercel Mirror:** [https://business-law-aid.vercel.app](https://business-law-aid.vercel.app)

---

## ✨ Features

- **Interactive Portal:** Centralized dashboard for accessing legal aid planning tools and resources.
- **Modern Responsive Design:** Fast, mobile-first interface optimized across desktop, tablet, and mobile browsers.
- **Automated Deployment:** CI/CD pipeline integrated via Vercel for fast updates and seamless production builds.

---

## 🛠️ Tech Stack

- **Frontend / Framework:** Next.js / React
- **Hosting & Deployment:** [Vercel](https://vercel.com/)
- **Domain & DNS:** Managed via custom sub-domain configuration (`plan.law-aid.org`)
